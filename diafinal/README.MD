# JOLU Grupo Digital - Proyecto final

Proyecto académico de diseño web responsivo centrado en la creación de una landing page corporativa y catálogo de productos para una empresa de biometría y seguridad.

## Tecnologías utilizadas
* HTML5 (Semántico y accesible)
* CSS3 (Flexbox, Grid, metodologías BEM, animaciones y transiciones)
* Vanilla JavaScript (Manipulación del DOM, eventos, IIFE, validaciones)

## Estructura
El proyecto ha sido optimizado aplicando buenas prácticas para el usuario, se usó lazy-loading de imágenes y validación nativa de formularios sin librerías de terceros, como indica la rúbrica del profesor.
